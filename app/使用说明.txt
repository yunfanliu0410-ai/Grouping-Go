顺路APP JavaScript 离线版

使用方法：
1. 解压整个文件包。
2. 保持 HTML 和 JS 两个文件在同一文件夹。
3. 双击“双击打开顺路APP.html”，或用 Chrome / Edge / Safari 打开。
4. 不需要联网、安装软件包或启动服务器。

“顺路APP_离线版.js”包含全部界面、样式和交互，不是只供查看的代码片段。
JS 文件通过 HTML 入口在浏览器中运行；不要通过 Windows 脚本宿主双击运行 JS。
新版名称、自由跳转、第3/4页广告、示例领券、路线计算均已包含。
数据仅存当前浏览器；示例编号不支持多人同步；无真实交易。
手机应用对本地 HTML 支持不同，优先使用电脑浏览器。
